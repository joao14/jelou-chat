# Guion de demo (≈2 min, grábalo con Loom/OBS)

1. (10s) Muestra el diagrama de arquitectura del README: WhatsApp → Jelou Brain Studio → API Go → PayPhone.
2. (60s) En WhatsApp: "hola" → elige película → función → "2 personas" → asientos A3 y A4 → confirma "sí".
3. (20s) Llega el link de pago → ábrelo → paga (PayPhone real o simulado).
4. (20s) Vuelve al chat: "ya pagué" → el agente verifica y entrega el ticket con código.
5. (10s) Muestra caso borde: intenta reservar los mismos asientos desde otro número → el agente ofrece alternativas.
6. (10s) Muestra `go test` pasando y el repo.
